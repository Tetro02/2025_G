# 当前架构与参数

以 `0c07eab` 的 XCI、RTL 与 C 源码为基线，优先于历史笔记和旧源码注释。

## 时钟和数据

- PL 时钟 50 MHz，顶层 `Test_Top`，器件 `xc7z020clg484-1`。
- 双路 ADC 各 12 位；学习/反馈采集按 167 倍抽取，实际采样率 50 MHz / 167 ≈ 299401.20 Hz，每帧 4096 点。该采集是取点抽取，没有 2026 FIR 主版本的 40 倍抗混叠抽取链路。
- 学习扫频 2048 点，起点与步进均 244.140625 Hz，终点 500 kHz。软件用已知激励频率 IQ 解调估计双路幅相；扫频激励上限不能直接理解为 299.4 kS/s 波形无混叠带宽。
- ADC1 为待测输出，ADC2 为输入参考，传递函数 H = ADC1 / ADC2；模仿路径使用 ADC2。
- 模仿路径每 50 个 PL 时钟送一个有效 FIR 输入，即 1 MS/s。校准路径则连续送 DDS 激励，50 MHz 有效输入；两条路径的有效输入速率不同，需在实物上验证校准迁移。

## FIR

`FIR_TAPS=1001`，XCI 为 `Single_Rate` / `Non_Symmetric` / `Coefficient_Reload=true`。当前算法根据处理后的幅频数据，通过 log-magnitude → 倒谱因果化 → 复指数 → IFFT 得到最小相位响应，再截断、加窗和量化。它不是对任意原电路相位的完整复现，不能保证保持非最小相位特性。

重载通道为 **1008 个 16 位字**，对应 IP 并行布局的对齐长度，顺序以 `fir_compiler_0_reload_order.txt` 为准。C 中 `reload_map` 与该文件核对；映射到系数索引 1001～1007 的位置必须填零。

PS 将系数放在 BRAM 字节偏移 **16400** 开始，每字 +4；16 位系数放在 32 位字高半字。PL 发送 reload 的 valid/ready/tlast，再通过 config 通道使配置生效。重载总线握手与实际板级波形仍需验证。

## 寄存器

自定义 AXI-Lite 基址 `0x43C00000`，BRAM 基址 `0x40000000`，GIC 中断 ID 61；最终以生成 BSP 为准。

| 偏移 | 含义 |
|---|---|
| 0x00 | 控制位：[0] ADC 采集、[1] FIR 重载、[2] DDS、[3] 模仿、[4] 校准 |
| 0x04 | DDS 频率字 [27:0]，DDS 时钟 50 MHz |
| 0x08 | DDS [20:13] 幅度、[12:11] 波形、[10:0] 相位 |
| 0x0C | [4:0] 算术右移 shift，[20:5] 无符号 Q1.15 微调系数 |

控制位包含互斥门控，不能随意叠加；以 `top.v` 中 cal_mode、fir_dac_mode 等表达式为准。FIR 重载位优先，学习/校准/模仿按软件流程切换。

`SKIP_SWEEP=0` 为默认完整学习；改为 1 会使用 `saved_fir.h` 和硬编码峰值参数，是调试分支，不能直接代表新被测电路。
