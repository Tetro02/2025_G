# 操作与硬件参考

## 已知接口

器件为 XC7Z020CLG484-1。XDC 定义双路 12 位 ADC 输入、ADC 时钟、14 位 DAC 数据及 DAC 时钟；原 RTL 注释提到 AD9226，但 ADC/DAC 具体模块版号、模拟前端、供电、终端阻抗和量程没有完整配套设计可核对。

PS DDR/MIO/晶振配置以 BD 和实际开发板原理图核对；不能把另一块 Zynq-7020 板的接口直接代入。此项目的 UART 与 2026 项目不同：**TX AB16，RX AA16**，约束 LVCMOS33。调试串口速率以新 BSP 的 UART 设置为准。

ADC1 记录待测电路输出，ADC2 记录输入参考。学习时 DDS 激励送待测电路并供 ADC2 参考；校准时按程序提示移除待测电路、接通直连反馈。DAC 到 ADC 的电气兼容、偏置和最大电压需按模块原理图确定，本文不把逻辑数据流当作模拟接线图。

## 默认执行流程

1. 通过 JTAG 或匹配的启动包运行 PS 应用，观察串口阶段提示。
2. 学习阶段完成 2048 个频点采样、后处理和幅相输出。
3. PS 计算最小相位 FIR，输出并按 IP 顺序重载系数。
4. 程序倒数 7 秒，提示断开外接滤波器并转为校准直连链路。
5. 自动粗调 shift、微调乘法系数，随后持续运行模仿路径。

当前程序有等待 ADC/中断的阻塞路径；无板或反馈链路未完成时可能一直等待。校准结果保存在运行时变量，未找到自动写入非易失存储的流程。

尚未提供设计报告、完整原理图/PCB/BOM、实物照片和量化误差数据；不能把 2026 G 题的 AD603/串口屏配置直接认定为本项目配置。
